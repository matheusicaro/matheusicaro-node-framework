# Changesets

Hello and welcome! This folder has been automatically generated by
`@changesets/cli`, a build tool that works with multi-package
repos, or single-package repos to help you version and publish your code.
You can find the full documentation for it [in our repository](https://github.com/changesets/changesets)

We have a quick list of common questions to get you started engaging with this
tool.

## How do I use git commit messages to write a changeset?

You don't! Changesets are created via `npx changeset` and are decoupled from
git. You can, however, generate them any way you want. See
[the automation docs](https://github.com/changesets/changesets/blob/main/docs/automation.md)
for more info.

## When do I add changesets?

Add a changeset any time your PR changes behavior in a way consumers should
know about — a feature, a bug fix, a breaking change. Skip it for internal
refactors, test-only changes, or documentation-only PRs.

## What do I do if I need to release with a major version?

If you wish to update the major version of your package, you need to add a
`major` changeset. See
[the versioning documentation](https://github.com/changesets/changesets/blob/main/docs/versioning-models.md)
for more information.
